# 批零价格涨跌传导的时滞资料约定

线路限定同品种、同规格、同片区的两端市场。报价单位可能是一市斤或一公斤，成交价全部为元/公斤。日期按中国标准时间归日，available_at 是当日资料实际可用时刻。缺报没有隐含价格，取消交易仍保留在证据表。批零匹配不保证同一条货流，地域与季节标签只描述观察背景。

## 数据表

### `routes`

同品规的批零匹配线路；市场代号仅为本地代号，单位重量是每报价单位的公斤数。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `species` | `text` |
| `grade` | `text` |
| `region` | `text` |
| `wholesale_market` | `text` |
| `retail_market` | `text` |
| `unit_kg` | `number` |

### `quotes`

报价不保证成交；price 按线路报价单位计价。缺行是未观测，挂牌与询价不可不加区分混合。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `route_id` | `text` |
| `day` | `date` |
| `side` | `text` |
| `price` | `money` |
| `quote_kind` | `text` |
| `available_at` | `time` |

### `trades`

成交单独以公斤计价，取消记录不产生真实成交；与报价没有逐笔一一关系。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `route_id` | `text` |
| `day` | `date` |
| `side` | `text` |
| `quantity_kg` | `number` |
| `unit_price_kg` | `money` |
| `cancelled` | `bool` |

### `calendar`

日期历表；季节是运营标记，不是已估计出的结构断点。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `date` |
| `weekday` | `int` |
| `holiday` | `bool` |
| `season` | `text` |

## 文件和数值语义

空单元格只在带问号的类型中表示缺失；零和空值不同。金额由十进制定点字符串保存，浮点数仅用于探索性统计。所有数据均为本地生成的虚构经营记录，不对应真实公司、客户或住址。数值剖面只反映观察数据，不能代替总体推断。

研究备注的参数为业务自由对象，不代表已执行了任何统计模型。原始表与已有视图可单独查询。

## 批零传导分析口径

`transmission` 分析在既有四表上计算，不新增资料来源，也不改动原始记录。

- 价格统一折算为元/公斤后再比较；线路 `unit_kg` 不是一的报价会放大金额尺度，分析只使用折算值。
- 缺报是未观测而非零涨跌：滞后项只在相邻日历日的报价差分上构造，跨缺口的目标日按该滞后期剔除，绝不前后填充。同日、窗口对齐（±N 日内最近报价并记录偏移天数）、成交日锚定三种匹配方式的样本规模差异在敏感性矩阵中并列展示。
- 挂牌与询价是两种报价口径，默认只使用挂牌；允许混合时响应会显式标注 `mixed_quote_kinds`，结论需按口径差异解读。
- 控制模型纳入线性趋势、星期效应、月份固定效应、节假日哑变量和同品种跨片区批发共振，用于排除共同趋势、季节性与地区共振造成的伪传导。两条曲线一起走低本身不构成传导证据。
- 累计关联分对称与非对称（批发上涨/下跌拆分）两套，不确定性同时给 HC3 保守解析区间和移动块自助区间；残差序列相关由 Ljung-Box 与 Breusch–Godfrey 检验，波动聚集由 ARCH-LM 检验，分布偏离由 Jarque–Bera 检验。
- 长期关系只用 Engle–Granger 两步法判断：协整残差 ADF-tau 未越过 MacKinnon 近似临界值时，不估计误差修正模型，只报告有边界的短期关联。
- 季节标记是运营背景而非已知断点；换季稳定性由分段系数、季节交互 Wald 检验与递归 CUSUM 共同判断，任一检验不稳健都会保留在响应中。
- 成交证据单独汇总：取消记录不计入成交，报价与成交价之差按配对日统计，价差的存在说明报价口径不能替代成交口径。
- 全部输出为观察性统计关联，不得表述为零售商加价的因果证据；样本量、覆盖率和不可估计原因随结果一并返回。
